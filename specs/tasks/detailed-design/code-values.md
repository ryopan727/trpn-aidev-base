# 固定コード値：タスク管理

文書の状態：決定済み

## 1. 対象と定義場所

タスクの状態と領域固有のエラーコードを対象とする。APIの正は[OpenAPI](../openapi.yaml)、業務上の意味は[要求仕様](../requirements.md)と[基本設計](../basic-design.md)。実装の状態定義は `app/tasks/domain/` に置く。共通エラーは[共通方針](../../../steering/api/error-handling.md)を参照する。

## 2. コード値と意味

| 分類 | 値 | 意味・条件 |
| --- | --- | --- |
| 状態 | `pending` | 未完了。新規登録時の値。 |
| 状態 | `completed` | 完了。完了操作で指定できる唯一の値。 |
| エラー | `TASK_NOT_FOUND` | 対象のタスクが存在しない。404。 |
| エラー | `INVALID_TASK_TITLE` | domainでタイトルの業務ルール違反を検知した。400。 |

## 3. 利用上の取り決め

状態はAPI・DBで同じ文字列を使い、表示用の日本語は保存値にしない。未知の状態やnullを既定値へ置き換えない。HTTP入力の違反は共通の `VALIDATION_ERROR`、JSON構文不備は `INVALID_JSON` とする。新しい状態の追加は要求・遷移・OpenAPI・保存・テストへの影響を確認してから行う。
