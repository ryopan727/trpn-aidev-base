# タスクごとのタグ付与・解除・一覧取得を追加

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-22 |
| サブドメイン | tasks |

## 1. 変更内容

タグ名を直接指定するPUT・DELETEと、タスク単位のタグ一覧GETを追加する。タスクとタスクタグを1対多で管理し、既存4 APIの応答は維持する。

## 2. 変更理由

ユーザーがタスクへタグを付けたいと指定した。事前登録・共有マスターを持たず、小さな範囲で分類を行えるようにする。再付与は重複を作らず成功、未付与の解除は共通DELETE方針どおり404とする。具体的な制約・設計はTASK-Q-004で承認済み。

## 3. 影響範囲

| 対象 | 影響 |
| --- | --- |
| 要求・設計 | REQ-005〜007、BR-004〜006、AC-011〜018を追加 |
| データ保存 | V2でtask_tagsを追加。既存タスクは保持し、初期タグ0件。既存SQLの書き換えは行わない |
| 実装・テスト | tasksの4層とbootstrap・例外登録を拡張。unit・PostgreSQL integration・実HTTP E2E、既存APIの回帰を検証 |
| ログ | タグ名を含む実パスを記録せず、既存のルートテンプレート方式を維持 |
